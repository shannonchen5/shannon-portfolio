# Track design files

These are **real vector design sources** (inline SVG geometry), not screenshots.

Generated by `node scripts/export-track-svgs.mjs` from the segment definitions in `lib/track-geometry.ts`.

## Editing

1. Change segments / colors in `lib/track-geometry.ts` (or the export script).
2. Re-run `node scripts/export-track-svgs.mjs`.
3. Open the SVGs in Figma, Illustrator, or a browser.

Lane count = 3. Stroke width ≈ gap. Caps are round. Parallel lanes are radius/normal offsets, not duplicated paths.
